# 看广告返钱功能设计

为激励用户活跃度，增加用户粘性，本模块设计“看广告返钱”功能，用户通过完成每日广告观看任务获得收益，收益可累积、预览、提现。后端实时计算预计收益，并提供历史收益记录。

---

## 1. 功能概述

- **每日任务**：用户每天可观看一定数量的广告，每观看一个广告获得固定收益。
- **收益计算**：后端记录每次观看，累计当日收益，并统计历史总收益。
- **预计收益**：根据今日已观看次数和剩余次数，计算今日预计可获得的总收益。
- **收益预览**：展示历史收益记录（按天或按次），支持查看收益明细。
- **提现功能**（可选）：达到最低提现门槛后可申请提现（本文档暂不详细展开，可后续扩展）。

## 2. 数据模型设计

### 2.1 广告任务配置表 `ad_task_config`

| 字段名          | 类型          | 说明                   |
| --------------- | ------------- | ---------------------- |
| `id`            | int           | 主键                   |
| `daily_limit`   | int           | 每日最大观看次数       |
| `reward_per_ad` | decimal(10,2) | 每次观看奖励金额（元） |
| `min_withdraw`  | decimal(10,2) | 最低提现金额（可选）   |
| `status`        | tinyint       | 1=启用，0=禁用         |

**说明**：系统只有一条配置记录，可动态调整。

### 2.2 用户广告观看记录表 `user_ad_watch`

| 字段名         | 类型          | 说明                   |
| -------------- | ------------- | ---------------------- |
| `id`           | bigint        | 主键ID                 |
| `user_id`      | bigint        | 用户ID                 |
| `watch_date`   | date          | 观看日期（yyyy-mm-dd） |
| `watch_count`  | int           | 当日已观看次数         |
| `today_earned` | decimal(10,2) | 当日已获得收益         |
| `created_at`   | datetime      | 记录创建时间           |
| `updated_at`   | datetime      | 更新时间               |

**索引**：`(user_id, watch_date)` 唯一索引，确保每个用户每天一条记录。

### 2.3 广告观看明细表 `ad_watch_detail`（可选，用于收益预览明细）

| 字段名       | 类型          | 说明                             |
| ------------ | ------------- | -------------------------------- |
| `id`         | bigint        | 主键ID                           |
| `user_id`    | bigint        | 用户ID                           |
| `ad_id`      | varchar(64)   | 广告ID（由广告平台返回，可为空） |
| `reward`     | decimal(10,2) | 本次观看获得收益                 |
| `watch_time` | datetime      | 观看时间                         |
| `ip`         | varchar(45)   | 用户IP                           |
| `user_agent` | text          | 用户代理                         |

**索引**：`user_id`，`watch_time`

### 2.4 用户总收益表 `user_earnings`

| 字段名         | 类型          | 说明                                  |
| -------------- | ------------- | ------------------------------------- |
| `id`           | bigint        | 主键ID                                |

| `total_earned` | decimal(10,2) | 历史累计收益                          |
| `withdrawn`    | decimal(10,2) | 已提现金额（若实现提现）              |
| `available`    | decimal(10,2) | 可提现金额 = total_earned - withdrawn |
| `updated_at`   | datetime      | 最后更新时间                          |

**说明**：每个用户一条记录，在第一次观看广告时创建。

## 3. 核心业务流程

### 3.1 每日任务初始化

- 每天0点，系统自动重置每个用户的当日观看记录（但保留历史明细）。
- 用户首次观看时，若当天无记录，则创建`user_ad_watch`记录，`watch_count`=1，`today_earned`=单次奖励。

### 3.2 观看广告流程

1. 用户点击“观看广告”按钮，前端请求后端获取广告（或直接调用广告SDK）。
2. 广告播放完成后，前端回调后端接口`POST /api/ad/watch`，携带广告ID等信息。
3. 后端处理：
   - 获取当天该用户观看记录，若无则创建。
   - 检查`watch_count`是否已达`daily_limit`，若已达，返回错误（广告已看完）。
   - 否则，`watch_count`+1，`today_earned`+=`reward_per_ad`。
   - 在`ad_watch_detail`中插入一条明细记录。
   - 更新`user_earnings`表：`total_earned`+=`reward_per_ad`，`available`+=`reward_per_ad`。
4. 返回成功，并附带本次收益、今日已获收益、剩余次数等信息。

### 3.3 预计收益计算

- 预计收益 = `今日已获收益` + `剩余可看次数 * 单次奖励`
- 剩余可看次数 = `daily_limit` - `今日已观看次数`
- 该数据可在用户打开任务面板时，通过接口`GET /api/ad/task-info`返回。

### 3.4 收益预览（历史记录）

- 支持按天查看：通过`user_ad_watch`表按日期倒序，返回每日收益。
- 支持按明细查看：通过`ad_watch_detail`表分页返回每次观看记录。

接口：

```
GET /api/ad/earnings?type=day   (按天汇总)
GET /api/ad/earnings?type=detail&page=1 (明细分页)
```

### 3.5 提现（可选扩展）

- 用户可申请提现，需满足`available >= min_withdraw`。
- 提现后生成提现记录，冻结相应金额，待处理完成后扣减。

## 4. 接口设计

### 4.1 获取任务信息

```
GET /api/ad/task-info
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "daily_limit": 10,
    "today_watched": 5,
    "reward_per_ad": 0.1,
    "today_earned": 0.5,
    "today_potential": 1.0, // 今日预计可获得总额（今日已获 + 剩余可看）
    "total_earned": 12.34,
    "available": 8.45
  }
}
```

### 4.2 观看广告回调

```
POST /api/ad/watch
```

**请求体**：

```json
{
  "ad_id": "广告平台返回的ID",
  "duration": 30 // 观看时长（秒），可选
}
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "reward": 0.1,
    "today_earned": 0.6,
    "today_left": 4,
    "total_earned": 12.44
  }
}
```

可能错误码：

- 403：今日次数已达上限
- 400：参数错误

### 4.3 获取收益历史（按天）

```
GET /api/ad/earnings/daily?page=1&page_size=20
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "total": 30,
    "items": [
      {
        "date": "2026-03-19",
        "earned": 0.8,
        "watch_count": 8
      },
      ...
    ]
  }
}
```

### 4.4 获取收益历史（明细）

```
GET /api/ad/earnings/detail?page=1&page_size=20
```

**响应**：

```json
{
  "code": 200,
  "data": {
    "total": 100,
    "items": [
      {
        "id": 123,
        "ad_id": "xxx",
        "reward": 0.1,
        "watch_time": "2026-03-19 10:30:00"
      },
      ...
    ]
  }
}
```

## 6. 注意事项与防作弊

- **频率限制**：同一用户两次观看广告之间需间隔一定时间（如10秒），防止快速刷量。
- **IP限制**：同一IP每天观看上限，防止机器刷。
- **设备限制**：记录设备ID，限制多账号刷。
- **广告真实性**：需与广告平台确认回调真实性，防止伪造回调。
- **数据一致性**：使用事务保证`user_ad_watch`和`user_earnings`同时更新。
- **并发处理**：使用乐观锁或数据库行锁避免超看。

## 8. 数据库建表SQL示例（MySQL）

```sql
-- 广告任务配置
CREATE TABLE `ad_task_config` (
  `id` int NOT NULL AUTO_INCREMENT,
  `daily_limit` int NOT NULL DEFAULT 10 COMMENT '每日最大观看次数',
  `reward_per_ad` decimal(10,2) NOT NULL DEFAULT '0.10' COMMENT '每次观看奖励（元）',
  `min_withdraw` decimal(10,2) DEFAULT '1.00' COMMENT '最低提现金额',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '1=启用',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 用户广告观看记录（按天汇总）
CREATE TABLE `user_ad_watch` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `user_id` bigint NOT NULL,
  `watch_date` date NOT NULL,
  `watch_count` int NOT NULL DEFAULT '0',
  `today_earned` decimal(10,2) NOT NULL DEFAULT '0.00',
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_date` (`user_id`,`watch_date`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 广告观看明细
CREATE TABLE `ad_watch_detail` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `user_id` bigint NOT NULL,
  `ad_id` varchar(64) DEFAULT NULL,
  `reward` decimal(10,2) NOT NULL,
  `watch_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `ip` varchar(45) DEFAULT NULL,
  `user_agent` text,
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_watch_time` (`watch_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 用户总收益表
CREATE TABLE `user_earnings` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `user_id` bigint NOT NULL,
  `total_earned` decimal(10,2) NOT NULL DEFAULT '0.00',
  `withdrawn` decimal(10,2) NOT NULL DEFAULT '0.00',
  `available` decimal(10,2) NOT NULL DEFAULT '0.00',
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_id` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 9. 后端示例代码（伪代码）

**观看广告接口实现**：

```php
public function watchAd(Request $request) {
    $user_id = auth()->id();
    $config = AdTaskConfig::first();
    $today = date('Y-m-d');

    DB::transaction(function () use ($user_id, $config, $today, $request) {
        $watch = UserAdWatch::firstOrCreate(
            ['user_id' => $user_id, 'watch_date' => $today],
            ['watch_count' => 0, 'today_earned' => 0]
        );

        if ($watch->watch_count >= $config->daily_limit) {
            throw new \Exception('今日次数已用完', 403);
        }

        $reward = $config->reward_per_ad;
        $watch->increment('watch_count');
        $watch->increment('today_earned', $reward);

        // 记录明细
        AdWatchDetail::create([
            'user_id' => $user_id,
            'ad_id' => $request->ad_id,
            'reward' => $reward,
            'ip' => $request->ip(),
            'user_agent' => $request->userAgent()
        ]);

        // 更新总收益
        $earnings = UserEarnings::firstOrCreate(['user_id' => $user_id]);
        $earnings->increment('total_earned', $reward);
        $earnings->increment('available', $reward);
    });

    // 返回今日最新数据
    return $this->taskInfo();
}
```
