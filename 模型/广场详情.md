# 广场详情页数据模型设计

广场详情页用于展示单篇公开日记的完整内容，包括日记信息、作者信息、互动数据、评论列表及相关推荐。本模型基于已有日记表和用户表，扩展了必要的关联查询和状态字段，为前端提供完整的详情数据。

---

## 1. 核心数据结构

### 1.1 日记详情字段

| 字段名       | 类型          | 说明                             |
| ------------ | ------------- | -------------------------------- |
| `id`         | string        | 日记ID                           |
| `title`      | string        | 标题                             |
| `content`    | string        | 完整正文（支持富文本/Markdown）  |
| `cover`      | string        | 封面图片URL                      |
| `images`     | array[string] | 正文图片列表                     |
| `tags`       | array[string] | 标签列表                         |
| `weather`    | string        | 天气（可选）                     |
| `mood`       | string        | 心情（可选）                     |
| `signature`  | string        | 签名（可选）                     |
| `location`   | string        | 地点名称                         |
| `created_at` | string        | 发布时间（ISO 8601）             |
| `updated_at` | string        | 最后更新时间                     |
| `diary_date` | string        | 日记写作日期（可不同于发布时间） |

### 1.2 作者信息

| 字段名                  | 类型    | 说明                   |
| ----------------------- | ------- | ---------------------- |
| `author`                | object  | 作者信息               |
| `author.id`             | string  | 用户ID                 |
| `author.nickname`       | string  | 昵称                   |
| `author.avatar`         | string  | 头像URL                |
| `author.bio`            | string  | 个人简介               |
| `author.follower_count` | int     | 作者粉丝数             |
| `author.is_followed`    | boolean | 当前用户是否已关注作者 |

### 1.3 互动统计与状态

| 字段名                | 类型    | 说明                       |
| --------------------- | ------- | -------------------------- |
| `stats`               | object  | 互动统计数据               |
| `stats.like_count`    | int     | 点赞总数                   |
| `stats.comment_count` | int     | 评论总数                   |
| `stats.share_count`   | int     | 分享总数                   |
| `stats.view_count`    | int     | 阅读数                     |
| `is_liked`            | boolean | 当前用户是否已点赞         |
| `is_favorited`        | boolean | 当前用户是否已收藏（可选） |
| `is_owner`            | boolean | 当前用户是否为日记作者     |

### 1.4 评论列表（分页）

| 字段名              | 类型   | 说明         |
| ------------------- | ------ | ------------ |
| `comments`          | object | 评论分页数据 |
| `comments.total`    | int    | 总评论数     |
| `comments.page`     | int    | 当前页码     |
| `comments.per_page` | int    | 每页条数     |
| `comments.items`    | array  | 评论列表     |

#### 评论项字段

| 字段名       | 类型    | 说明                                 |
| ------------ | ------- | ------------------------------------ |
| `id`         | string  | 评论ID                               |
| `user`       | object  | 评论用户信息（id, nickname, avatar） |
| `content`    | string  | 评论内容                             |
| `like_count` | int     | 评论点赞数                           |
| `is_liked`   | boolean | 当前用户是否点赞该评论               |
| `created_at` | string  | 评论时间                             |
| `reply_to`   | object  | 回复目标（可选，若支持楼中楼）       |

### 1.5 相关推荐（可选）

| 字段名            | 类型  | 说明                                                                 |
| ----------------- | ----- | -------------------------------------------------------------------- |
| `recommendations` | array | 推荐日记列表（简要卡片，包含id、title、cover、author、like_count等） |

## 4. 数据库查询逻辑

### 4.1 获取日记详情

```sql
SELECT d.*, u.nickname, u.avatar, u.bio, u.follower_count
FROM diaries d
INNER JOIN users u ON d.user_id = u.id
WHERE d.id = :diary_id AND d.is_public = 1 AND d.status = 1
LIMIT 1;
```

### 4.2 检查当前用户是否点赞

```sql
SELECT 1 FROM likes WHERE user_id = :current_user_id AND diary_id = :diary_id LIMIT 1;
```

### 4.3 检查是否关注作者

```sql
SELECT 1 FROM follows WHERE follower_id = :current_user_id AND following_id = :author_id LIMIT 1;
```

### 4.4 获取评论列表（分页）

```sql
SELECT c.*, u.nickname, u.avatar,
       (SELECT 1 FROM comment_likes WHERE user_id = :current_user_id AND comment_id = c.id) AS is_liked
FROM comments c
INNER JOIN users u ON c.user_id = u.id
WHERE c.diary_id = :diary_id AND c.status = 1
ORDER BY c.created_at DESC
LIMIT :offset, :limit;
```

### 4.5 获取推荐日记（简单示例：同标签或同作者）

```sql
SELECT d.id, d.title, d.cover, u.nickname, u.avatar, d.like_count
FROM diaries d
INNER JOIN users u ON d.user_id = u.id
WHERE d.is_public = 1 AND d.status = 1
  AND d.id != :current_diary_id
  AND (d.user_id = :author_id OR JSON_OVERLAPS(d.tags, :tags))
ORDER BY d.like_count DESC
LIMIT 6;
```

## 5. 性能优化建议

- **缓存**：对于热门日记，可将详情页数据缓存（如Redis）5-10分钟，减少数据库压力。
- **计数冗余**：`like_count`、`comment_count` 在日记表冗余存储，避免实时count。
- **分页**：评论列表使用游标分页（基于created_at）而非offset，提高性能。
- **索引**：为`comments`表建立`(diary_id, status, created_at)`索引。
