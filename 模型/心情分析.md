# 日记分析页面设计（ECharts + 关怀语录）

基于之前的日记分析模型，为用户设计一个直观、温暖的数据分析界面，通过图表展示情绪趋势、主题分布、写作习惯等，并配合情感关怀语录，让用户在了解自己的同时获得正向鼓励。

---

## 1. 页面整体布局

页面采用上下结构或左右分栏，根据屏幕尺寸自适应。设计延续毛玻璃风格，圆润卡片，柔和阴影。

## 2. ECharts 图表设计

### 2.1 情绪趋势折线图
- **数据**：最近30天（或周）的情感得分（-1到1）
- **交互**：显示数据点，可悬浮查看具体日期和得分
- **样式**：用渐变填充，积极区域暖色，消极区域冷色，中性灰色

```javascript
option = {
  title: { text: '情绪趋势', left: 'center' },
  tooltip: { trigger: 'axis' },
  xAxis: { data: ['3/1', '3/2', ...] },
  yAxis: { name: '情感值', min: -1, max: 1 },
  series: [{
    type: 'line',
    data: [0.5, 0.3, -0.2, 0.4, ...],
    areaStyle: {
      color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
        { offset: 0, color: 'rgba(111,168,220,0.3)' },
        { offset: 1, color: 'rgba(111,168,220,0)' }
      ])
    },
    lineStyle: { color: '#6FA8DC', width: 2 }
  }]
};
```

### 2.2 主题分布饼图
- **数据**：各主题出现次数占比
- **交互**：悬浮显示主题和百分比，点击可跳转到该主题日记列表
- **样式**：柔和配色，避免刺眼

```javascript
option = {
  tooltip: { trigger: 'item' },
  series: [{
    type: 'pie',
    radius: '50%',
    data: [
      { name: '生活', value: 45 },
      { name: '工作', value: 30 },
      { name: '旅行', value: 15 }
    ],
    label: { show: true, formatter: '{b}: {d}%' }
  }]
};
```

### 2.3 写作习惯雷达图
- **维度**：早晨、下午、晚上、深夜（或按星期分布）
- **数据**：各时段日记数量占比
- **样式**：填充半透明，网格线细

```javascript
option = {
  radar: {
    indicator: [
      { name: '早晨(6-12)', max: 100 },
      { name: '下午(12-18)', max: 100 },
      { name: '晚上(18-22)', max: 100 },
      { name: '深夜(22-6)', max: 100 }
    ]
  },
  series: [{
    type: 'radar',
    data: [{ value: [12, 35, 89, 20], name: '写作习惯' }]
  }]
};
```

### 2.4 关键词词云
- **数据**：高频关键词及权重
- **实现**：使用 `echarts-wordcloud` 扩展
- **交互**：点击关键词可搜索相关日记

```javascript
option = {
  series: [{
    type: 'wordCloud',
    shape: 'circle',
    sizeRange: [12, 60],
    rotationRange: [-90, 90],
    data: [
      { name: '开心', value: 85 },
      { name: '周末', value: 72 },
      { name: '朋友', value: 48 }
    ]
  }]
};
```

## 3. 关怀语录模块

### 3.1 语录生成规则
根据最近日记的综合情感得分、主题分布、连续写作天数等，从预定义库中选取合适的语录。同时可结合天气、心情等元数据（如果有）。

**语录库示例**（支持动态参数）：
- 情感积极（>0.5）：“今天的你看起来心情不错呢！愿这份快乐延续到每一天 🌞”
- 情感中性（-0.2~0.5）：“平淡的日子也藏着美好，继续用心记录吧 📝”
- 情感消极（<-0.2）：
  - “我知道你或许有些低落，但没关系，写下来就是一种释放。明天会更好 💪”
  - “难过的时候，允许自己休息一下。你做得已经很好了 🌈”
- 连续写作奖励：“你已经连续记录7天啦！坚持是件了不起的事 🌟”
- 主题特定（如“工作”+消极）：“工作压力是暂时的，记得照顾好自己 💼”

### 3.2 接口返回
后端分析完日记后，返回最近情感得分、连续天数等，前端根据规则选择语录。也可后端直接生成一个“关怀消息”字段。

### 3.3 前端展示
- 使用毛玻璃卡片，内部包含头像/表情、标题、正文、可选的配图。
- 每天刷新，或每次进入分析页面动态生成。
- 增加“换一句”按钮，用户可手动刷新新语录（从同类型语录中随机）。

## 4. 页面交互与数据加载

### 4.1 数据获取
页面加载时请求接口：
- `GET /api/user/analysis/overview`：获取概览（情感分布、主题占比等）
- `GET /api/user/analysis/sentiment-trend?type=week`：情绪趋势数据
- `GET /api/user/analysis/wordcloud`：词云数据
- `GET /api/user/analysis/writing-habit`：写作习惯（时段分布）
- 关怀语录：可前端根据情感得分和主题自行生成，也可后端返回 `caring_message`

### 4.2 ECharts 初始化
在 `onReady` 或 `mounted` 中初始化各图表，监听窗口尺寸变化调用 `resize`。

### 4.3 加载状态
显示骨架屏或 loading 动画，图表区域可先显示占位。

## 5. 代码实现（uniapp + Vue3 + ECharts）

### 5.1 安装 echarts
在项目中安装 echarts：
```bash
npm install echarts
```

对于小程序，需使用 `echarts-for-uniapp` 或自定义 canvas 渲染。推荐使用 `lime-echarts` 插件，或直接使用官方 `ec-canvas` 组件。

由于 uniapp 小程序不支持直接使用 DOM 操作，echarts 官方提供了 `echarts-for-weixin` 的适配方式，但 uniapp 中可借助 `renderjs` 或第三方组件。为简化，我们采用 `renderjs` 方式在 App 和 H5 端实现，小程序端可使用 `lime-echarts` 插件。

## 6. 后端接口补充

根据之前设计的模型，需提供以下接口供前端调用：
- `GET /api/user/analysis/overview`：返回概览数据（情感分布、主题占比、写作习惯、词云数据、连续天数等）
- `GET /api/user/analysis/sentiment-trend`：返回情绪趋势时间序列
- 也可将关怀语录在后端生成，直接返回 `caring_message` 字段，减少前端逻辑。

## 7. 多端适配与性能优化

- **小程序**：ECharts 使用 `lime-echarts` 或 `ec-canvas` 组件，需将容器指定为 `canvas` 并调整初始化方式。
- **图表懒加载**：仅在进入页面时加载一次，避免重复渲染。
- **数据缓存**：分析结果可缓存1小时，减少请求压力。
- **交互反馈**：点击图表或词云关键词时，可跳转到相应日记列表（如点击“旅行”主题，跳转到该主题的日记列表）。
