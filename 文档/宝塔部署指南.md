# 宝塔面板部署指南

## 前置要求

- 宝塔面板已安装
- Node.js >= 16（推荐通过宝塔「软件商店」安装 PM2管理器，会自动装 Node.js）
- MongoDB >= 4.4（宝塔软件商店安装）
- MySQL >= 5.7（宝塔软件商店安装，可选）

## 部署步骤

### 1. 上传项目

通过宝塔「文件」面板，将 `note-backend-v*.zip` 上传到服务器，例如：

```
/www/wwwroot/note-backend/
```

解压后目录结构应为：

```
/www/wwwroot/note-backend/
├── index.js
├── package.json
├── ecosystem.config.js
├── .env.example
├── config/
├── middleware/
├── models/
├── routes/
├── utils/
└── ...
```

### 2. 配置环境变量

```bash
cd /www/wwwroot/note-backend
cp .env.example .env
```

编辑 `.env`，填入实际配置：

```env
PORT=3005
JWT_SECRET=你的JWT密钥（随机字符串）
MONGODB_URI=mongodb://localhost:27017/note
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=你的MySQL密码
MYSQL_DATABASE=note
EMAIL_USER_NAME=你的邮箱
EMAIL_PASSWORD=邮箱授权码
EMAIL_HOST=smtp.qq.com
EMAIL_PORT=465
CLEAR_DATABASE=false
```

### 3. 安装依赖

```bash
cd /www/wwwroot/note-backend
npm install --production
```

### 4. 创建必要目录

```bash
mkdir -p logs uploads
```

### 5. 启动服务

```bash
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup  # 设置开机自启
```

### 6. 宝塔反向代理配置

在宝塔面板中：

1. 「网站」→ 添加站点，填入你的域名
2. 点击站点名 → 「反向代理」→ 添加反向代理
3. 配置如下：
   - 代理名称：`note-api`
   - 目标URL：`http://127.0.0.1:3005`
   - 发送域名：`$host`

或者直接编辑 Nginx 配置，在 server 块中添加：

```nginx
location / {
    proxy_pass http://127.0.0.1:3005;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

### 7. 配置 SSL（推荐）

在宝塔面板中：站点 → SSL → Let's Encrypt → 申请免费证书

## 常用运维命令

```bash
# 查看状态
pm2 status

# 查看日志
pm2 logs note-backend

# 重启
pm2 restart note-backend

# 停止
pm2 stop note-backend

# 更新代码后重启
cd /www/wwwroot/note-backend
npm install --production
pm2 restart note-backend
```

## 注意事项

- `.env` 文件不在打包中，需要手动创建
- `uploads/` 目录用于存储上传文件，注意备份
- `logs/` 目录会自动创建，定期清理
- MongoDB 建议开启认证，生产环境不要用默认无密码连接
- `CLEAR_DATABASE` 务必设为 `false`，否则启动会清空数据库
