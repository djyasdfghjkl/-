# 表情包管理接口设计

基于您的需求，为用户提供更多可选择的丰富表情包，设计一套完整的表情包管理系统。包括官方表情包库、用户自定义上传、表情包收藏、使用频率统计等功能。

---

## 1. 核心功能需求

- **官方表情包库**：提供多套预设表情包（如基础表情、动态GIF、节日限定等）
- **用户自定义上传**：允许用户上传自己的图片作为表情包
- **表情包分类**：按类型、主题、热门程度分类
- **收藏与下载**：用户可收藏喜欢的表情包，下载到本地
- **使用频率统计**：记录表情使用次数，推荐热门表情
- **标签与搜索**：支持关键词搜索表情包

## 2. 数据模型设计

### 2.1 表情包表 `emojis`

| 字段名          | 类型         | 说明                                |
| --------------- | ------------ | ----------------------------------- |
| `id`            | bigint       | 主键ID                              |
| `uuid`          | varchar(64)  | 表情包唯一标识（对外使用）          |
| `name`          | varchar(100) | 表情名称                            |
| `description`   | varchar(255) | 描述                                |
| `type`          | tinyint      | 类型：1=静态图片，2=GIF动图，3=APNG |
| `category_id`   | int          | 分类ID                              |
| `url`           | varchar(500) | 表情文件URL（CDN地址）              |
| `thumbnail_url` | varchar(500) | 缩略图URL（用于列表展示）           |
| `tags`          | json         | 标签数组，如["开心","搞笑","猫"]    |
| `is_official`   | tinyint(1)   | 是否官方表情：1=是，0=用户上传      |
| `uploader_id`   | bigint       | 上传者用户ID（用户上传时记录）      |
| `status`        | tinyint      | 状态：1=正常，0=审核中，-1=禁用     |
| `file_size`     | int          | 文件大小（字节）                    |
| `file_hash`     | varchar(64)  | 文件哈希值（用于去重）              |
| `width`         | int          | 图片宽度                            |
| `height`        | int          | 图片高度                            |
| `duration`      | int          | 动图时长（毫秒，仅动图）            |
| `use_count`     | bigint       | 使用次数统计                        |
| `created_at`    | datetime     | 创建时间                            |
| `updated_at`    | datetime     | 更新时间                            |

| 字段名       | 类型         | 说明     |

## 3. 接口列表

### 3.1 基础管理接口

#### 获取表情包分类列表

```
GET /api/emoji/categories
```

**响应**：

```json
{
  "code": 200,
  "data": [
    {
      "id": 1,
      "name": "热门推荐",
      "icon": "/static/icons/hot.png"
    },
    {
      "id": 2,
      "name": "搞笑",
      "icon": "/static/icons/funny.png"
    }
  ]
}
```

#### 获取表情包列表（分页）

```
GET /api/emojis
```

**请求参数**：

- `category_id`（可选）：分类ID
- `type`（可选）：表情类型（1静态/2GIF）
- `keyword`（可选）：搜索关键词
- `page`：页码，默认1
- `page_size`：每页条数，默认20

**响应**：

```json
{
  "code": 200,
  "data": {
    "total": 200,
    "page": 1,
    "page_size": 20,
    "items": [
      {
        "id": "emoji_uuid_123",
        "name": "猫猫震惊",
        "type": 2,
        "url": "https://cdn.example.com/emojis/cat.gif",
        "thumbnail": "https://cdn.example.com/emojis/cat_thumb.png",
        "tags": ["猫", "震惊", "搞笑"],
        "is_favorite": true,
        "use_count": 1523
      }
    ]
  }
}
```

#### 获取表情包详情

```
GET /api/emojis/{uuid}
```

**响应**：返回单个表情包的详细信息

#### 官方表情包下载/安装

```
POST /api/emojis/{uuid}/install
```

用户下载官方表情包到本地（实际是记录到用户关联表）

#### 热门表情推荐

```
GET /api/emojis/trending
```

返回近期使用频率高的表情包

---

### 3.2 用户相关接口

#### 获取用户收藏的表情包

```
GET /api/user/emojis/favorites
```

分页返回用户收藏的表情包列表

#### 收藏/取消收藏表情包

```
POST /api/user/emojis/favorite
```

**请求体**：

```json
{
  "emoji_uuid": "emoji_123",
  "action": "add" // 或 "remove"
}
```

> 根据交互设计原则，相同接口应该实现状态切换：再次点击相同表情自动取消收藏

#### 记录表情使用（用户发送表情时调用）

```
POST /api/user/emojis/usage
```

**请求体**：

```json
{
  "emoji_uuid": "emoji_123"
}
```

后端记录使用次数，用于统计和推荐

#### 获取用户常用表情（近期使用）

```
GET /api/user/emojis/recent
```

返回用户最近使用的表情包列表（按使用时间倒序）

---

### 3.3 自定义表情包接口

#### 上传自定义表情包

```
POST /api/user/emojis/custom
```

**Content-Type**: `multipart/form-data`

**请求参数**：

- `file`：图片文件（支持jpg/png/gif/webp，最大5MB）
- `name`：自定义名称（可选）

**处理流程**：

1. 文件格式校验
2. 计算文件哈希值，检查是否已存在（去重）
3. 上传到对象存储，生成URL
4. 生成缩略图
5. 记录到`user_custom_emojis`表

**响应**：

```json
{
  "code": 200,
  "data": {
    "id": "custom_123",
    "url": "https://cdn.example.com/user/123/emoji.png",
    "name": "我的表情"
  }
}
```

#### 获取用户自定义表情包列表

```
GET /api/user/emojis/custom
```

返回用户上传的所有自定义表情

#### 删除自定义表情包

```
DELETE /api/user/emojis/custom/{id}
```

---

### 3.4 管理后台接口（管理员用）

#### 上传官方表情包（批量）

```
POST /api/admin/emojis/batch
```

支持一次性上传多个表情包，并设置分类、标签

#### 审核用户上传表情（若需公开）

```
POST /api/admin/emojis/review
```

将用户上传的表情审核后加入官方库

#### 更新表情包数据

```
PUT /api/admin/emojis/{uuid}
```

修改表情包的名称、分类、标签等

#### 禁用/删除表情包

```
DELETE /api/admin/emojis/{uuid}
```

## 4. 表情包存储与优化建议

### 4.1 存储方案

- **CDN加速**：所有表情包文件存储在CDN上，确保全球用户快速加载
- **对象存储**：使用阿里云OSS/腾讯云COS等，支持自动裁剪缩略图
- **格式优化**：静态图优先使用WebP格式，动图使用压缩后的GIF或APNG

### 4.2 图片处理

- **缩略图生成**：统一生成100x100缩略图用于列表展示
- **尺寸规范**：官方表情建议统一尺寸（如100x100）
- **文件大小限制**：静态图<200KB，动图<1MB

### 4.3 性能优化

- **懒加载**：表情包面板使用懒加载，滚动时加载更多
- **预加载**：用户打开表情面板时，预加载常用表情
- **本地缓存**：使用次数高的表情包缓存到本地存储

### 4.4 去重机制

用户上传自定义表情时，通过感知哈希（pHash）算法检测是否与现有表情重复，减少存储浪费

## 5. 使用频率统计与推荐算法

### 5.1 统计维度

- 全局热门：所有用户使用次数
- 用户个性化：该用户使用次数
- 时段热门：近期使用激增的表情

### 5.2 推荐策略

- **猜你喜欢**：基于用户历史使用标签推荐相似表情
- **大家都在用**：全局热门表情
- **新表情推荐**：新上线的官方表情

## 6. 表关系示意图

```
emojis
  ├── category_id -> emoji_categories.id
  ├── uploader_id -> users.id (用户上传时)
  └── tags -> emoji_tags (多对多，可用JSON简化)

user_emoji_favorites
  ├── user_id -> users.id
  └── emoji_id -> emojis.id

user_emoji_usage
  ├── user_id -> users.id
  └── emoji_id -> emojis.id

user_custom_emojis
  └── user_id -> users.id
```

## 7. 交互设计建议

### 7.1 表情选择器

- 分类选项卡横向滑动
- 表情网格每行4-5个
- 长按表情显示放大预览
- 点击表情直接发送（同时记录使用）

### 7.2 收藏功能

- 表情右上角心形图标标记收藏状态
- 收藏夹独立分类显示
- 支持批量管理收藏

### 7.3 自定义表情

- 提供上传入口，支持从相册选择
- 上传后自动添加到“我的表情”分类
- 支持重命名和删除

### 7.4 搜索功能

- 支持按名称和标签搜索
- 实时搜索建议
- 最近搜索记录

      - name: category_id

      - name: keyword
        in: query
        schema: string
      - name: page
        in: query
        schema: integer

        description: 成功
        content:
          application/json:
            schema:
              type: object
              properties:
                total: integer
                items: array
