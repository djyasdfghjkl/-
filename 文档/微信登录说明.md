# 微信一键登录功能说明

## 功能概述

本项目已支持微信小程序一键登录功能，用户可以通过微信授权快速登录或注册账号。

## 功能特性

1. **微信一键登录**：用户只需提供微信小程序的code即可完成登录或注册
2. **自动创建用户**：新用户首次登录时会自动创建账号
3. **用户信息解密**：支持获取微信用户昵称、头像等信息
4. **账号绑定**：已登录用户可以绑定微信账号
5. **JWT认证**：登录成功后返回JWT token，用于后续API调用

## 配置步骤

### 1. 获取微信小程序凭证

1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册并登录你的微信小程序账号
3. 在「开发」→「开发管理」→「开发设置」中获取：
   - **AppID**：小程序ID
   - **AppSecret**：小程序密钥

### 2. 配置环境变量

在项目根目录的 `.env` 文件中添加以下配置：

```env
# 微信小程序配置
WECHAT_APP_ID=你的微信小程序AppID
WECHAT_APP_SECRET=你的微信小程序AppSecret
```

## API接口说明

### 1. 微信一键登录

**接口地址**：`POST /api/users/wechat-login`

**请求参数**：
```json
{
  "code": "微信小程序登录code",
  "encryptedData": "加密的用户数据（可选）",
  "iv": "加密算法的初始向量（可选）"
}
```

**响应示例**：
```json
{
  "success": true,
  "message": "微信登录成功",
  "data": {
    "user": {
      "id": "用户ID",
      "uuid": "用户UUID",
      "username": "用户名",
      "nickname": "昵称",
      "avatar": "头像地址",
      "role": 0,
      "status": 1,
      ...
    },
    "token": "JWT token",
    "isNewUser": false,
    "loginStats": { ... },
    "awardedMedals": [ ... ]
  }
}
```

### 2. 绑定微信账号

**接口地址**：`POST /api/users/wechat-bind`

**需要认证**：是（Bearer Token）

**请求参数**：
```json
{
  "code": "微信小程序登录code"
}
```

**响应示例**：
```json
{
  "success": true,
  "message": "微信绑定成功",
  "data": {
    "wx_openid": "微信openid",
    "wx_unionid": "微信unionid"
  }
}
```

## 小程序端实现示例

### 1. 获取登录code

```javascript
// 在小程序中调用
wx.login({
  success: (res) => {
    if (res.code) {
      // 发送code到后端
      this.wechatLogin(res.code);
    } else {
      console.log('登录失败！' + res.errMsg);
    }
  }
});
```

### 2. 调用登录接口

```javascript
async wechatLogin(code) {
  try {
    const response = await wx.request({
      url: 'https://你的域名/api/users/wechat-login',
      method: 'POST',
      data: {
        code: code
      },
      success: (res) => {
        if (res.data.success) {
          // 保存token
          wx.setStorageSync('token', res.data.data.token);
          wx.setStorageSync('userInfo', res.data.data.user);
          
          // 登录成功后的处理
          if (res.data.data.isNewUser) {
            console.log('新用户注册成功');
          } else {
            console.log('老用户登录成功');
          }
          
          // 跳转到首页或用户中心
          wx.switchTab({
            url: '/pages/index/index'
          });
        } else {
          wx.showToast({
            title: res.data.message || '登录失败',
            icon: 'none'
          });
        }
      },
      fail: (err) => {
        console.error('登录请求失败', err);
        wx.showToast({
          title: '网络错误',
          icon: 'none'
        });
      }
    });
  } catch (error) {
    console.error('登录出错', error);
  }
}
```

### 3. 获取用户信息（可选）

如果你需要获取用户的昵称、头像等信息，可以使用 `getUserProfile`：

```javascript
// 注意：需要用户主动触发按钮点击
getUserInfo() {
  wx.getUserProfile({
    desc: '用于完善用户资料',
    success: (res) => {
      const { encryptedData, iv } = res;
      
      // 获取code后一起发送到后端
      wx.login({
        success: (loginRes) => {
          this.wechatLoginWithUserInfo(loginRes.code, encryptedData, iv);
        }
      });
    }
  });
}

async wechatLoginWithUserInfo(code, encryptedData, iv) {
  const response = await wx.request({
    url: 'https://你的域名/api/users/wechat-login',
    method: 'POST',
    data: {
      code: code,
      encryptedData: encryptedData,
      iv: iv
    },
    success: (res) => {
      // 处理登录成功
    }
  });
}
```

## 注意事项

1. **AppID和AppSecret安全**：
   - 不要将AppSecret提交到代码仓库
   - 在生产环境中使用环境变量管理
   - 定期更换AppSecret

2. **用户数据加密**：
   - 只有在需要用户昵称、头像等信息时才需要 encryptedData 和 iv
   - 简单登录只需要 code 即可

3. **Code有效期**：
   - 微信的code只能使用一次
   - code有效期为5分钟
   - 建议获取code后立即调用后端接口

4. **UnionID机制**：
   - 如果同一开发者账号下有多个小程序或公众号，可以通过UnionID关联用户
   - 需在微信公众平台绑定开发者账号

5. **测试环境**：
   - 在开发阶段可以使用微信开发者工具的测试号
   - 正式上线需要使用已认证的小程序

## 调试技巧

1. **查看后端日志**：在服务器控制台查看微信登录的详细日志
2. **检查网络请求**：在微信开发者工具的Network标签中查看请求和响应
3. **验证环境变量**：确保 .env 文件中的微信配置正确
4. **测试接口**：使用Postman或Swagger文档测试微信登录接口
