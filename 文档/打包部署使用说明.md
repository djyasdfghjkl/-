# 打包部署使用说明

## 📦 可用的npm命令

### 1. 开发命令
```bash
# 启动开发服务器（带热重载）
npm run dev

# 直接启动服务器
npm start
```

### 2. 打包部署命令
```bash
# 完整打包流程（清理 + 打包）
npm run build

# 仅清理临时文件和日志
npm run clean

# 仅打包项目
npm run pack

# 安装生产环境依赖（用于服务器）
npm run deploy:prep
```

### 3. PM2管理命令（服务器上使用）
```bash
# 启动应用
npm run pm2:start

# 停止应用
npm run pm2:stop

# 重启应用
npm run pm2:restart

# 查看日志
npm run pm2:logs
```

## 🚀 完整部署流程

### 第一步：本地打包

```bash
# 1. 进入项目目录
cd d:\study\myCode\note

# 2. 执行打包命令
npm run build

# 3. 打包完成后，在 dist/ 目录下会生成压缩包
# 文件名类似：note-backend-v1.0.0-2026-03-27T12-34-56.tar.gz
```

### 第二步：上传到服务器

使用SCP或其他工具上传压缩包到服务器：
```bash
# 在本地执行（替换为你的服务器信息）
scp dist/note-backend-v1.0.0-xxx.tar.gz root@your-server-ip:/var/www/
```

### 第三步：服务器上部署

```bash
# 1. SSH连接到服务器
ssh root@your-server-ip

# 2. 进入目标目录
cd /var/www

# 3. 解压压缩包
tar -xzf note-backend-v1.0.0-xxx.tar.gz

# 4. 进入解压后的目录
cd note-backend-v1.0.0-xxx

# 5. 复制环境变量配置
cp .env.example .env

# 6. 编辑环境变量（修改数据库、微信等配置）
nano .env

# 7. 安装生产依赖
npm install --production

# 8. 创建必要的目录
mkdir -p uploads logs

# 9. 使用PM2启动应用
pm2 start ecosystem.config.js

# 10. 设置PM2开机自启
pm2 startup
pm2 save
```

### 第四步：配置Nginx（如果还没配置）

```bash
# 1. 复制nginx配置
cp nginx.conf /etc/nginx/sites-available/note

# 2. 创建软链接
ln -s /etc/nginx/sites-available/note /etc/nginx/sites-enabled/

# 3. 编辑配置，修改域名和路径
nano /etc/nginx/sites-available/note

# 4. 测试配置
nginx -t

# 5. 重启Nginx
systemctl restart nginx
```

### 第五步：配置SSL证书（如果需要）

```bash
# 安装Certbot
apt install -y certbot python3-certbot-nginx

# 获取证书
certbot --nginx -d yourdomain.com
```

## 📂 打包内容说明

打包会包含以下内容：
- ✅ index.js - 应用入口
- ✅ package.json - 项目配置
- ✅ ecosystem.config.js - PM2配置
- ✅ nginx.conf - Nginx配置
- ✅ config/ - 配置文件目录
- ✅ middleware/ - 中间件目录
- ✅ models/ - 数据模型目录
- ✅ routes/ - 路由目录
- ✅ scripts/ - 脚本目录
- ✅ utils/ - 工具函数目录
- ✅ 文档/ - 部署文档

打包会自动排除：
- ❌ node_modules/ - 依赖包（服务器上重新安装）
- ❌ .git/ - Git仓库
- ❌ .env - 本地环境变量
- ❌ logs/ - 日志文件
- ❌ uploads/ - 上传文件
- ❌ dist/ - 打包输出目录

## 🔍 常见问题

### 问题1：Windows下无法使用tar命令

**解决方案：**
- 安装Git Bash，使用Git Bash终端执行打包命令
- 或使用WSL (Windows Subsystem for Linux)
- 或直接使用Node.js原生打包方式（脚本会自动检测）

### 问题2：打包后文件太大

**解决方案：**
- 检查是否不小心包含了node_modules
- 清理logs和uploads目录后再打包
- 使用`npm run clean`先清理

### 问题3：服务器上启动失败

**排查步骤：**
```bash
# 1. 查看PM2日志
pm2 logs note-backend --err

# 2. 检查端口是否被占用
netstat -tlnp | grep 3005

# 3. 手动启动测试
node index.js

# 4. 检查环境变量
cat .env

# 5. 检查数据库连接
systemctl status mongod
systemctl status mysql
```

### 问题4：如何更新部署

```bash
# 1. 本地重新打包
npm run build

# 2. 上传新包到服务器
scp dist/new-package.tar.gz root@your-server-ip:/var/www/

# 3. 服务器上操作
cd /var/www
tar -xzf new-package.tar.gz
cd new-package-directory

# 4. 复制旧的.env文件
cp ../old-package-directory/.env .

# 5. 安装新依赖（如果有）
npm install --production

# 6. 重启应用
pm2 restart note-backend
```

## 📊 PM2常用命令

```bash
# 查看所有应用状态
pm2 status

# 查看应用详情
pm2 show note-backend

# 查看实时日志
pm2 logs note-backend

# 查看错误日志
pm2 logs note-backend --err

# 清空日志
pm2 flush

# 监控应用
pm2 monit

# 停止应用
pm2 stop note-backend

# 重启应用
pm2 restart note-backend

# 删除应用
pm2 delete note-backend

# 保存PM2进程列表
pm2 save

# 重新加载PM2配置
pm2 reload ecosystem.config.js
```
