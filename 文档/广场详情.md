# 广场详情页面设计

基于已有的广场页面和模型，设计一个完整的日记详情页，包含日记完整内容、作者信息、互动区、评论列表和相关推荐。页面延续整体高级感风格，采用毛玻璃卡片、柔和阴影、圆润圆角，并适配多主题。同时融入Lottie点赞动画，提升交互趣味性。

## 2. 组件样式细节

### 2.1 顶部栏

- 半透明毛玻璃背景，高度 96rpx。
- 左侧返回箭头，中间标题（可显示“日记详情”或截断的日记标题），右侧更多图标（分享/举报）。
- 使用CSS变量：背景`var(--surface)`，文字`var(--text-primary)`。

### 2.2 封面图

- 若日记有封面，全宽显示，高度 400rpx，object-fit cover。
- 若没有封面，则不显示该区域。
- 支持点击预览大图。

### 2.3 日记卡片

- 毛玻璃背景，圆角`--radius-xl`，内边距 32rpx，边距左右 32rpx。
- **标题**：`--font-size-title`（44rpx），加粗。
- **正文**：`--font-size-body`（32rpx），行高 1.6，颜色`--text-primary`。
- **图片网格**：最多三列，每列等宽，圆角`--radius-md`，间隔 8rpx。点击可预览。
- **元数据行**：使用图标+文字，字体`--font-size-caption`（24rpx），颜色`--text-secondary`，水平排列。
- **标签**：类似首页，可点击搜索相关。

### 2.4 作者卡片

- 毛玻璃卡片，内边距 32rpx，圆角`--radius-xl`。
- 左侧头像（80rpx圆形），右侧昵称和简介。
- 粉丝数显示，右侧关注按钮（主色边框或填充）。

### 2.5 互动栏

- 三个按钮水平均分，每个包含图标和计数。
- 点赞按钮使用Lottie动画（点击播放心形动画），同时数字变化。
- 评论按钮点击聚焦评论输入框。
- 分享按钮调起分享面板。

### 2.6 评论区域

- **评论标题**：显示评论总数，右侧可能有排序按钮。
- **评论输入框**：点击展开输入区域（可输入文字、表情）。
- **评论项**：
  - 左侧小头像（48rpx）。
  - 右侧昵称、时间、内容。
  - 底部有点赞按钮（Lottie或静态）和回复按钮。
  - 若为回复，显示“回复 @昵称”。
- **加载更多**：滑动到底部自动加载，或点击“加载更多”。

### 2.7 相关推荐

- 横向滚动容器，左右内边距 32rpx。
- 推荐卡片（宽度 240rpx，高度 320rpx），包含封面（120rpx）、标题、作者昵称、点赞数。
- 点击进入对应日记详情。

### 2.8 动画与交互

- **点赞**：使用Lottie心形动画，点击时播放，数字+1（若已点赞则取消）。
- **关注**：点击后按钮文案切换为“已关注”，背景变淡。
- **图片预览**：调用`uni.previewImage`。
- **标签点击**：跳转到广场页并自动搜索该标签。
- **评论输入**：使用`textarea`自适应高度，可插入表情（可选）。

## 4. 交互与功能说明

| 功能             | 交互说明                                                   | 技术实现                 |
| ---------------- | ---------------------------------------------------------- | ------------------------ |
| **点赞**         | 点击心形图标播放Lottie动画，数字+1；再次点击取消，数字-1。 | Lottie组件 + API调用     |
| **关注**         | 点击按钮切换文字和样式，更新作者is_followed状态。          | 本地状态 + API           |
| **评论输入**     | 点击输入框跳转到评论页或弹出评论面板（本设计简化）。       | 跳转到新页面或使用弹出层 |
| **评论点赞**     | 点击评论的心形，更新点赞状态。                             | 调用API，更新本地计数    |
| **图片预览**     | 点击图片调用`uni.previewImage`。                           | uni API                  |
| **标签点击**     | 点击标签跳转到广场页并自动搜索该标签。                     | 跳转并传参               |
| **相关推荐**     | 横向滚动，点击卡片跳转到对应详情页。                       | 跳转传id                 |
| **加载更多评论** | 滑动到底部自动加载下一页。                                 | 监听scrolltolower事件    |
| **分享**         | 点击分享按钮调起系统分享或小程序分享面板。                 | uni.share                |

## 5. 主题适配

所有颜色、圆角、阴影均使用CSS变量，页面自动适配当前主题（基础、机甲、暗黑、粉色可爱等）。各主题的装饰元素（如背景图案、按钮符号）通过主题类自动生效。

---

## 6. 多端适配注意事项

- **图片预览**：`uni.previewImage` 在所有端表现一致。
- **评论输入**：小程序中点击输入框会触发键盘，需注意页面滚动。
- **Lottie动画**：使用通用Lottie组件，根据平台自动降级。
- **滚动加载**：`scroll-view` 的 `@scrolltolower` 在App和小程序均支持。
- **安全区域**：底部留出 `env(safe-area-inset-bottom)`。

## 7. 扩展建议

- **评论回复功能**：可增加回复列表，使用嵌套评论组件。
- **举报/拉黑**：在更多菜单中添加举报和拉黑选项。
- **收藏功能**：增加收藏按钮，与点赞类似。
- **长按复制**：长按正文可复制内容。
