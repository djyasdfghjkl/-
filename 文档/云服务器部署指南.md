# 云服务器部署完整指南

## 📋 前提条件

1. **云服务器**：腾讯云/阿里云/华为云等（推荐Ubuntu 20.04/22.04）
2. **域名**：已购买并解析到服务器IP
3. **SSH访问**：能通过SSH连接到服务器

---

## 🚀 第一步：服务器环境准备

### 1.1 连接到服务器

```bash
ssh root@your-server-ip
```

### 1.2 更新系统软件包

```bash
apt update && apt upgrade -y
```

### 1.3 安装Node.js（推荐Node.js 18+）

```bash
# 安装Node.js 18 LTS
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs

# 验证安装
node -v
npm -v
```

### 1.4 安装PM2（进程管理）

```bash
npm install -g pm2
```

### 1.5 安装Nginx

```bash
apt install -y nginx

# 启动Nginx
systemctl start nginx
systemctl enable nginx
```

### 1.6 安装MongoDB

```bash
# 导入MongoDB公钥
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | apt-key add -

# 添加MongoDB仓库
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# 安装MongoDB
apt update
apt install -y mongodb-org

# 启动MongoDB
systemctl start mongod
systemctl enable mongod
```

### 1.7 安装MySQL（可选，根据项目需要）

```bash
apt install -y mysql-server

# 安全配置
mysql_secure_installation

# 启动MySQL
systemctl start mysql
systemctl enable mysql
```

## 📦 第二步：部署项目

### 2.1 上传项目到服务器

有多种方式上传项目：

**方式1：使用Git（推荐）**
```bash
# 在服务器上克隆项目
cd /var/www
git clone your-repo-url note
cd note
```

**方式2：使用SCP上传**
```bash
# 在本地执行
scp -r /path/to/your/note root@your-server-ip:/var/www/
```

### 2.2 安装项目依赖

```bash
cd /var/www/note
npm install
```

### 2.3 配置环境变量

```bash
# 复制示例配置
cp .env.example .env

# 编辑配置文件
nano .env
```

修改以下内容：
```env
PORT=3005
JWT_SECRET=your-production-secret-key-here
MONGODB_URI=mongodb://localhost:27017/note
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=your-mysql-password
MYSQL_DATABASE=note
WECHAT_APP_ID=your-wechat-app-id
WECHAT_APP_SECRET=your-wechat-app-secret
CLEAR_DATABASE=false
```

### 2.4 创建必要的目录

```bash
mkdir -p uploads logs
```

## 🔧 第三步：配置Nginx

### 3.1 复制Nginx配置

```bash
# 复制配置文件到Nginx目录
cp /var/www/note/nginx.conf /etc/nginx/sites-available/note

# 创建软链接
ln -s /etc/nginx/sites-available/note /etc/nginx/sites-enabled/

# 删除默认配置（可选）
rm /etc/nginx/sites-enabled/default
```

### 3.2 编辑Nginx配置

```bash
nano /etc/nginx/sites-available/note
```

修改以下内容：
- `yourdomain.com` → 你的实际域名
- `/path/to/your/note` → `/var/www/note`

### 3.3 测试Nginx配置

```bash
nginx -t
```

如果显示`syntax is ok`和`test is successful`，说明配置正确。

### 3.4 重启Nginx

```bash
systemctl restart nginx
```

## 🔒 第四步：配置SSL证书（HTTPS）

### 4.1 安装Certbot

```bash
apt install -y certbot python3-certbot-nginx
```

### 4.2 获取SSL证书

```bash
certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

按照提示操作：
- 输入邮箱地址
- 同意服务条款
- 选择是否重定向HTTP到HTTPS（推荐选择2：Redirect）

### 4.3 自动续期

Certbot会自动设置定时任务续期证书，可以测试一下：

```bash
certbot renew --dry-run
```

## 🚀 第五步：启动应用

### 5.1 使用PM2启动应用

```bash
cd /var/www/note

# 编辑ecosystem.config.js，修改cwd路径
nano ecosystem.config.js
# 将 /path/to/your/note 改为 /var/www/note

# 启动应用
pm2 start ecosystem.config.js

# 设置开机自启
pm2 startup
pm2 save
```

### 5.2 查看应用状态

```bash
# 查看PM2管理的应用
pm2 status

# 查看日志
pm2 logs note-backend

# 实时监控
pm2 monit
```

## 🔥 第六步：防火墙配置

### 6.1 配置UFW防火墙

```bash
# 允许SSH
ufw allow 22/tcp

# 允许HTTP和HTTPS
ufw allow 80/tcp
ufw allow 443/tcp

# 启用防火墙
ufw enable

# 查看状态
ufw status
```

## 🔍 常见问题排查

### 问题1：Referer校验问题

如果你遇到请求被拦截的问题，检查：

1. **后端代码**：确认没有Referer校验（我们的代码没有）
2. **Nginx配置**：确认nginx.conf中没有`valid_referers`配置
3. **云服务器安全组**：确认云服务器安全组开放了80和443端口

### 问题2：CORS跨域问题

我们已经修复了CORS配置，如果还有问题：

1. 检查前端请求地址是否正确
2. 确认Nginx配置正确
3. 查看浏览器控制台错误信息

### 问题3：PM2应用无法启动

```bash
# 查看错误日志
pm2 logs note-backend --err

# 检查端口是否被占用
netstat -tlnp | grep 3005

# 手动启动测试
cd /var/www/note
node index.js
```

### 问题4：数据库连接失败

```bash
# 检查MongoDB状态
systemctl status mongod

# 检查MySQL状态
systemctl status mysql

# 测试连接
mongo
mysql -u root -p
```
