如果你的目标是 **现在先让小程序能访问接口，后面再迁移到轻量服务器 + 域名**，其实有个最省事的方案 👍

## ⭐ 推荐方案：先用 Vercel

原因很简单：

- 部署 **最快**（几分钟）
- 自带 **HTTPS**（小程序必须）
- 有 **公网域名**
- 后面换服务器 **只改接口地址**

---

# 最简单做法（不用改太多代码）

你的 Koa 项目只需要做 **3 步**。

## ① 安装适配库

```bash
npm install serverless-http
```

---

## ② 新建 Vercel 入口

创建文件：

```
/api/index.js
```

代码：

```javascript
const serverless = require("serverless-http");
const app = require("../index"); // 你的koa入口

module.exports = serverless(app);
```

注意：

如果你 `index.js` 里有：

```javascript
app.listen(3000);
```

要改成：

```javascript
module.exports = app;
```

---

## ③ 新建 vercel.json

```json
{
  "routes": [
    {
      "src": "/(.*)",
      "dest": "/api/index.js"
    }
  ]
}
```

---

## ④ 部署

安装 CLI：

```bash
npm i -g vercel
```

部署：

```bash
vercel
```

成功后你会得到：

```
https://xxxx.vercel.app
```

---

# 小程序配置

去 **微信开发者工具**

设置：

```
开发管理
↓
开发设置
↓
服务器域名
```

添加：

```
https://xxxx.vercel.app
```

# 之后迁移服务器也很简单

等你买了：

- 腾讯云轻量应用服务器
- 或 阿里云轻量应用服务器

只需要：

1️⃣ 部署 Node
2️⃣ 绑定域名
3️⃣ 修改小程序接口地址

比如：

```
https://api.xxx.com
```

---

# ⚠️ 有两个小注意

**1️⃣ Vercel 不适合**

- 文件上传
- WebSocket
- 长任务

但普通 API 完全够。

**2️⃣ MySQL**

要用公网数据库。
